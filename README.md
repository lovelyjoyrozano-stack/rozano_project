# A Random Regression-Based Climate and Crop Productivity Monitoring and Decision Support System for Farmers

## Summary
A web-based decision support system designed to assist local farmers and agricultural stakeholders in monitoring climate trends, predicting crop productivity using regression-based modeling, and making data-driven agricultural decisions.

## Current stack
Flutter Web / Dart; planned REST API and PostgreSQL.

## Run locally
flutter pub get
flutter run -d chrome
